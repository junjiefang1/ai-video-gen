- **核心架构**：采用 Vite + React + TypeScript 构建，通过 `src/lib/video-providers.ts` 抽象层统一调度 HappyHorse、Kling V3 Omni 和 Muledance 2.0 等多模态视频模型。
- **功能分层**：`src/components` 负责 UI 交互（含 TabNav 模式切换），`src/hooks` 封装复杂状态逻辑（如 `useBatchQueue` 实现带容错级联的批量队列），`src/lib` 提供底层能力（API 适配、ffmpeg.wasm 本地拼接、Qwen 视觉分镜拆解）。
- **代理机制**：在 `vite.config.ts` 中内置 `/dashscope` 和 `/mulerouter` 代理中间件，解决跨域请求与第三方 CDN 资源（如 Volcengine）的 CORS 限制。
- **长视频链路**：实现了从 Prompt 拆解（`prompt-decompose.ts`）到分段生成、尾帧衔接（Chain Frames）、字幕烧录（`video-text-overlay.ts`）及最终 ffmpeg 拼接的完整自动化流水线。
